MIS 발주 버튼

발주앱에 넣은 오늘 발주수량을 MIS 주문등록에 넣고 주문그룹별로 저장까지 해 줍니다.

1. 버튼 설치 (PC 크롬, 처음 한 번)
  1. Ctrl + Shift + B로 즐겨찾기 막대를 켭니다.
  2. 아래 검은 버튼을 마우스로 끌어서 즐겨찾기 막대에 놓습니다.

앱 발주 넣기

끌어 놓기가 안 되면: 즐겨찾기 막대 우클릭 → 페이지 추가 → 이름 "앱 발주 넣기", URL에 아래 글을 통째로 붙여넣기
2. 쓰는 법
  1. 발주앱에서 오늘 발주수량을 넣습니다.
  2. MIS → 주문등록 화면을 엽니다 (주문 마감 14:30 전).
  3. 즐겨찾기 막대의 앱 발주 넣기를 누릅니다 → 넣을 목록 확인 → 확인.
  4. 온세물류 → 새싹농산 … 그룹을 차례로 열어 수량을 넣고 저장합니다. 끝날 때까지 기다려 주세요 (10~30초).
  5. 끝나면 결과가 뜹니다: 그룹별 저장 개수, 못 찾은 품목, MIS 안내.
3. 폰에서 보내기 (PC 자동 대기)
  1. 아래 MIS 자동 대기 버튼도 즐겨찾기 막대로 끌어 놓습니다 (처음 한 번).
  2. PC에서 MIS → 주문등록 화면을 열고 MIS 자동 대기를 누릅니다 → 탭 제목에 [자동대기]가 붙고 오른쪽 아래에 상태가 떠요.
  3. 그 탭은 열어 둔 채로 두세요 (닫거나 새로고침하면 꺼져요. 다시 누르면 켜짐).
  4. 폰 발주앱 → 발주 탭의 GW 전송 버튼 → 20초 안에 PC가 넣고 저장 → 폰에 결과가 떠요.

MIS 자동 대기

끌어 놓기가 안 되면: 페이지 추가 → 이름 "MIS 자동 대기", URL에 아래 글을 통째로
4. PC 켜 두기만 하면 (크롬 확장 · 추천)
  1. gw-agent.zip 내려받기 → 압축 풀기 (예: 문서 폴더. 지우면 안 돼요)
  2. 크롬 주소창에 chrome://extensions → 오른쪽 위 개발자 모드 켜기 → 압축해제된 확장 프로그램 로드 → 푼 gw-agent 폴더 선택
  3. 주소창 오른쪽 퍼즐 아이콘 → 발주앱 GW 자동입력 핀 고정 → 눌러서 GW 아이디·비밀번호 입력, 자동입력 켜기 체크 → 저장
  4. MIS가 고정 탭으로 열리고 로그인 → 주문등록 → 자동 대기까지 알아서 해요. 확장 창에 "✓ 자동 대기 중"이 뜨면 끝.
  5. PC를 켜면 크롬이 자동으로 켜지게: Win + R → shell:startup → 열린 폴더에 크롬 바로가기 복사
  6. 절전 끄기: 설정 → 시스템 → 전원 → 화면·절전 안 함
아이디·비밀번호는 이 PC 크롬 안에만 저장돼요. 로그인 실패는 30분에 2번까지만 시도해서 계정이 잠기지 않아요. MIS·VPN 연결이 끊기면 5분마다 다시 열어 봐요.
5. 매장 PC 자동 켜기 (사람 손 없이)
  1. 윈도우 자동 로그인: 설정 → 계정 → 로그인 옵션 → "Windows Hello 로그인만 허용" 끔 → Win + R → netplwiz → "사용자 이름과 암호를 입력해야…" 체크 해제 → 확인 → 비밀번호 두 번
  2. 크롬 자동 실행: Win + R → shell:startup → 열린 폴더에 크롬 바로가기 복사
  3. 절전 끄기: 설정 → 시스템 → 전원 → 화면·절전 안 함
  4. 매일 아침 자동 켜짐 (BIOS): PC 켤 때 Del 또는 F2 연타 → 전원(Power) 메뉴 → RTC Alarm / Power On By RTC / Resume By Alarm → Enabled · 매일(Every Day) · 09:00 → F10 저장
  5. BIOS에 그 메뉴가 없으면: Restore on AC Power Loss → Power On으로 바꾸고 스마트 플러그(매일 09:00 켜짐)에 PC 전원 연결. 이때는 밤에 윈도우가 먼저 꺼지게 아래 6번 필수
  6. (스마트 플러그일 때) 밤 자동 종료: 시작 → cmd 우클릭 관리자 실행 → schtasks /create /tn PCoff /tr "shutdown /s /f /t 60" /sc daily /st 23:00
  7. 아침에 안 켜지면: 제어판 → 전원 옵션 → 전원 단추 작동 설정 → "빠른 시작 켜기" 끔
확인: PC를 끄고 → 다음 날 09:00 이후 폰 발주앱에 "PC 자동 대기 중"이 뜨면 성공.
앱 발주는 구글 시트에서 읽기만 합니다. MIS에는 주문수량만 넣고 저장하며, 저장 뒤 그룹을 다시 불러와 수량이 맞는지 대조합니다.
