MIS 발주 버튼

발주앱에 넣은 오늘 발주수량을 MIS 주문등록 화면에 채워 줍니다. 저장은 직접 누르세요.

1. 버튼 설치 (PC 크롬, 처음 한 번)
  1. Ctrl + Shift + B로 즐겨찾기 막대를 켭니다.
  2. 아래 검은 버튼을 마우스로 끌어서 즐겨찾기 막대에 놓습니다.

앱 발주 넣기

끌어 놓기가 안 되면: 즐겨찾기 막대 우클릭 → 페이지 추가 → 이름 "앱 발주 넣기", URL에 아래 글을 통째로 붙여넣기
2. 쓰는 법
  1. 발주앱에서 오늘 발주수량을 넣습니다.
  2. MIS → 주문등록 → 주문그룹(온세물류 등)을 엽니다.
  3. 즐겨찾기 막대의 앱 발주 넣기를 누릅니다 → 넣을 목록 확인 → 확인.
  4. 노란 줄을 확인하고 MIS [저장]을 누릅니다.
  5. "이 화면에 없는 품목"이 나오면 다른 주문그룹(새싹농산 등)을 열고 버튼을 다시 누릅니다.
앱 발주는 구글 시트에서 읽기만 합니다. MIS에는 주문수량 칸만 채우고, 저장·전송은 하지 않습니다.
