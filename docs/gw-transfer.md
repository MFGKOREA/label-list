# GW 전송 (폰 → 그룹웨어 MIS 자동 발주) 정리 · 2026-10-24

## 한 줄
폰 발주앱에서 **GW 전송**을 누르면, PC 크롬에 열려 있는 MIS 주문등록 화면이 오늘 발주수량을 넣고 주문그룹별로 **저장**까지 하고, 결과를 폰에 돌려준다.

## 흐름
```
폰 발주앱 [GW 전송] ─→ 구글 시트 misPush {date, status: pending}
                              │  (20초마다 확인)
PC 크롬 확장 gw-agent(1.3.2, 평소 창 없음) ─ 30초마다 시트 확인 → pending이면 최소화 창으로 GW 로그인 → 경영정보 → MIS 주문등록
   → 자동 대기(mis-agent.js) ─→ mis.js: 그룹 열기 → 수량 넣기 → 저장 → 다시 불러와 대조 → 끝나면 창 닫음 (12분 넘으면 닫고 같은 요청 2번까지)
                              │
구글 시트 misPush {status: done/error, text, saved/total} ─→ 폰에 "✓ 저장 완료 N/N" 또는 "⚠ 확인 필요"
misAgent: 창 없을 땐 확장이 10분마다 {mode: ondemand}, 창 열려 있을 땐 자동 대기가 2분마다 → 폰에 "PC 대기 중 / PC 연결 안 됨"
```

## 구성 (저장소)
| 파일 | 하는 일 |
|---|---|
| `mis.js` | MIS 입력·저장 본체. 북마크 **앱 발주 넣기**(확인창 있음)와 자동 대기(확인창 없음)가 같이 씀 |
| `mis-agent.js` | 자동 대기. 시트 확인 · 실행 · 결과 기록 · 살아 있음 · MIS 로그인 유지(10분) |
| `gw-agent/` (+ `gw-agent.zip`) | 크롬 확장. PC가 켜지면 GW 로그인 → 경영정보 → MIS → 주문등록 → 자동 대기까지 |
| `order-src/app.js` `renderMis` | 폰 화면의 "그룹웨어 자동입력" 칸과 [GW 전송] 버튼 |
| `mis.html` | 설치 안내 (북마크 2개, 확장 설치) |
| `order-src/test/gw/` | 가짜 MIS·GW로 하는 시험 (진짜 시트·MIS에 안 씀) |

시트 키: `misPush`(오늘 전송 요청·결과), `misAgent`(PC 살아 있음), `input.YYYY-MM-DD`의 `o`(발주수량, 안 넣은 품목은 `0`).

## 남은 일 (GW 전송 팀)
1. **GW 자동 로그인 확인** — 10/24엔 KM이 직접 로그인. 확장 기록 캡처로 원인 확인 (확장 1.1 설치 여부, GW 로그인 화면 구조)
2. **동시 실행 막기** — 탭 2개(북마크 자동 대기 + 확장)가 같이 받으면 하나가 "이미 입력 중이에요"로 실패를 덮어씀 → running 잠금(누가·언제) + "이미 입력 중"은 실패로 안 적고 잠시 뒤 다시
3. **확장 시험 환경** — Playwright가 확장·새 창 탭을 못 가로챔 → 로컬 HTTPS 서버 + `--host-resolver-rules`로 GW→MIS 새 창까지 시험
4. **휴무일 운영** — 윈도우 자동 로그인·절전 끔·크롬 시작 프로그램, VPN(집)·매장망 끊김 때 폰 표시
5. **보안** — 비밀번호는 PC 크롬 저장소에만. 채팅에 적은 GW 비밀번호는 바꾸기 (KM)
6. **시트 쓰기 보호** — 시트 API는 주소만 알면 POST로 쓸 수 있고(주소가 공개 저장소에 있음) misPush pending이면 PC가 실제로 저장함 → GW 전송·발주수량 쓰기에 PIN/서명 확인 검토 (J 10/24 지적)
7. **MIS에 이미 있는 수량** — 앱에 없는 품목은 MIS에서 안 지움(예: 테스트로 넣은 등심). 전송 전 확인 화면에 "MIS에만 있는 품목" 보여 주기 검토
