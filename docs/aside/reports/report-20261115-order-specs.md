## 결과 3줄
1. 라자냐 생면(선인 파스타 알 우보 라사니아 2.5kg×4): 한 장 **195g, 45×24cm** (선인 공식). 팩당 장 수는 공식 표기 없음 → 2,500÷195 ≈ **12.8장(추정, 약 12~13장)**.
2. 델베르데 리가토니(No.19): **500g 맞음** (라벨·제조사), 조리 11분. 삶은 무게는 제조사 안내 **못 찾음**.
3. 만다린오렌지(세이웰) 830g: 세이웰 상품 페이지 자체를 **못 찾음** → 고형량·조각 수·조각 무게 모두 못 찾음.

## 못 한 것
- 만다린오렌지(세이웰) 830g: 못 찾음. 검색어: `세이웰 만다린 오렌지 830g 고형량`, `"세이웰" 만다린오렌지`, `Saywell/SEYWELL 만다린`, `"만다린오렌지(세이웰)"`, `만다린오렌지 830g 고형량`. 다른 브랜드(해울찬·명진·코끼리·장사골든) 830g 페이지에도 고형량 표기는 없었음. 조각 수·조각 무게는 공개 웹에 없음.
- 라자냐 팩당 장 수: 공식 표기 없음(위 12.8은 추정).
- 리가토니 삶은 무게: 델베르데 공식·수입사 페이지에 안내 없음. (참고만: 호주·뉴질랜드 식품기준청 일반 건파스타 삶음 중량변화 +131% → 500g ≈ 1,155g, 추정이며 제조사 값 아님. https://www.foodstandards.gov.au/business/labelling/nutrition-panel-calculator/weight-change-factors)

## 후속 제안
- 만다린: KM이 매장 캔 라벨의 "고형량" 사진을 찍어 주거나, 한 캔 건더기 무게·조각 수를 한 번 재면 가장 정확.
- 라자냐: 한 팩 장 수를 매장에서 한 번 세어 확인(추정 12~13장).
- 리가토니: 매장 방식대로 500g 한 봉 삶은 뒤 무게를 한 번 재서 환산값으로 쓰기.
