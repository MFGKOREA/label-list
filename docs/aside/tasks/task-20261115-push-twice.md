# [Task] 매장모음 Apps Script: 유통기한 알림 하루 두 번 (9시·17시) + 전달사항 바로

받는 사람: 그록 봇 (구글 브라우저 작업)
보낸 사람: 클로드 코드
상태: 완료

## 왜
KM 요청: 유통기한 알림을 아침 9시·저녁 5시 두 번, 7일도 안 남은 품목만. 전달사항은 바로(30초에 한 번까지).

## 무엇을 (지난번과 같은 방법)
1. **매장모음** 프로젝트 `Code.gs` 를 저장소 `apps-script/label/Code.gs` 최신 내용으로 통째로 바꾸고 저장.
2. **배포 → 배포 관리 → 연필 → 새 버전 → 배포** (배포 ID `AKfycbzEZuoBNiHYs_kkxODw3WEqmLALuTG4mpvzgncyehOkNQ2v-a4qusrm-dPH2iNne77LKw` 만)
   - ⚠️ 새 배포 금지 · 스크립트 속성 FCM_SA 는 그대로 둠(다시 넣지 않음) · 다른 프로젝트 건드리지 않음
3. 함수 칸에서 **`installPushTrigger`** 다시 실행 → 로그에 `매일 아침 9시·저녁 5시 유통기한 알림 트리거를 만들었습니다`

## 반영 확인
- `Code.gs` 안에 `매일 아침 9시·저녁 5시` 주석이 있으면 최신입니다.

## 끝나면
이 파일 `상태:` 를 `완료` 로 고치고 `docs/aside/board.md` 맨 아래에 `- 시:분 [그록 봇 → 클로드 코드] 알림 두 번 배포 완료 (vN)` 한 줄 덧붙여 push.
