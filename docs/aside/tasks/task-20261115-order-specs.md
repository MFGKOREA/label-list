# [Task] 품목 규격 3가지 찾기 (만다린 캔, 라자냐 생면, 리가토니)

받는 사람: 그록 봇 (집 PC 브라우저)
보낸 사람: 클로드 코드 (발주앱 세션)
상태: 대기

규칙: `docs/aside/tasks/task-20261115-order-support.md` 를 먼저 읽고 그대로 지킨다.

## 무엇을
발주앱 레시피 계산에 필요한 품목 규격 3가지를 **공개 웹**에서 찾는다. 지금은 이 값을 몰라 앱이 세 프랩(Mandarine, Lasagna Ready, Cooked Rigatoni)의 원재료 사용량을 0으로 계산한다.

## 대상 (헷갈리기 쉬우니 꼭 확인)
| 품목 (발주 목록 이름) | 규격 (발주 목록) | 찾을 것 |
|---|---|---|
| 만다린오렌지(세이웰) | 830g 캔, 12캔/박스 | 고형량(건더기 g), 한 캔에 든 귤 조각 수(대략), 조각 하나 무게 |
| 라자냐생면(선인 / 파스타 알 우보 라자냐) | 2.5kg, 4개/박스 | 한 장 크기(cm)·한 장 무게(g)·2.5kg 한 팩에 든 장 수 |
| 델베르데리가토니 | 500g, 20봉/박스 | 한 봉지 500g이 맞는지, 삶으면 몇 g이 되는지(제조사 안내가 있으면) |

❌ 쇼핑몰에서 장바구니·구매·로그인을 하지 않는다. 상품 상세 페이지를 보기만 한다.

## 순서
1. 검색창에 품목 이름과 규격을 그대로 넣어 검색한다(예: `세이웰 만다린 오렌지 830g 고형량`). 결과 목록이 보일 때까지 기다린다.
2. 제조사·수입사 공식 페이지를 먼저 본다. 없으면 식자재 쇼핑몰 상품 상세 페이지(규격표·라벨 사진)를 본다.
3. 값을 찾으면 출처 URL·페이지 날짜·화면에 적힌 문구 그대로를 적어 둔다. 두 곳 이상이 다르면 둘 다 적는다.
4. 공개 웹페이지 화면은 `docs/aside/reports/assets/20261115-order-specs-*.png` 로 저장해도 된다(로그인·개인정보가 보이면 저장하지 않음).
5. 찾지 못하면 "못 찾음"이라고 쓰고 무엇을 검색했는지 적는다. 숫자를 짐작해서 채우지 않는다.

## 확인
| 확인 | 방법 | 정상 기준 |
|---|---|---|
| 세 품목 모두 답이 있는지 | 보고서 표 | 값 또는 "못 찾음" + 검색어 |
| 출처가 있는지 | 값마다 URL·날짜 | 값마다 1개 이상 |
| 같은 상품인지 | 상품명·용량이 발주 목록과 같은지 | 830g 캔 / 2.5kg / 500g |

## 끝나면
1. 이 파일의 `상태:` 를 `완료` (또는 `막힘: 이유`) 로 고친다.
2. `docs/aside/reports/report-20261115-order-specs.md` 에 결과 3줄, 품목별 표(값·출처 URL·날짜·원문), 못 찾은 것, 후속 제안을 적는다.
3. `docs/aside/board.md` 맨 아래에 `- MM/DD HH:MM [그록 봇 → 클로드 코드] 규격 3가지 보고` 를 덧붙이고, 커밋 메시지 앞에 `[그록 봇]` 을 붙여 push 한다.
