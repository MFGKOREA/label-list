## 무엇을
- **할 일:** MIS(경영정보) 월재고마감 화면을 찾아 **조회만** 하고, 화면 구조를 아래 표 모양으로 적는다.
- **끝 기준:** 아래 "보고 표" 6칸이 다 차 있고, 스크린샷 3장(메뉴 경로 · 조회 결과 위쪽 · 입력 칸/버튼 부분)을 KM에게 넘겼다.
- **보고 예시 한 줄:** `경로: 경영정보 › 매입정보관리 › 재고관리 › 월재고마감 · 열: 품목코드|품목명|규격|단위|전산재고|실사재고(입력)|차이 · 단위 예: PK, EA, KG`
- **보고 모양:** 결과 3줄 → 보고 표 → 막힌 곳.

❌ 건드리지 않음: 저장 · 마감 · 확정 · 삭제 · 엑셀 올리기 · 다른 매장 선택.

## 순서
1. GW에서 경영정보(MIS)를 연다. 왼쪽 메뉴가 보일 때까지 기다린다.
2. 왼쪽 메뉴에서 "월재고", "재고마감", "재고실사", "실사재고"가 들어간 메뉴를 찾는다. 접힌 폴더는 펼친다. 찾은 메뉴 이름과 부모 경로를 **모두** 적는다(여러 개면 다 적음).
3. 그중 월재고마감(또는 재고실사 입력) 화면을 연다. 조회 조건(년월·매장·창고·분류 칸)을 적는다.
4. 이번 달(없으면 지난달)로 맞추고 **[조회]만** 누른다. 표가 나올 때까지 기다린다.
   - ⚠️ [저장]·[마감]·[확정]·[엑셀업로드]는 누르지 않는다. 월말 재고 숫자가 바뀌어 원가·손익이 틀어진다.
5. 표의 열 이름을 왼쪽부터 그대로 적는다. 어느 열에 숫자를 **입력**하게 되어 있는지(칸을 누르면 글자 입력이 되는지) 적는다. 눌러서 확인만 하고 값은 바꾸지 않는다. 바뀌었으면 [조회]를 다시 눌러 되돌린다.
6. "단위" 열이 있으면 서로 다른 단위 값을 10개까지 적는다(예: PK, EA, KG, BOX, CAN). 단위 열이 없으면 "단위 열 없음".
7. 품목 5개만 골라 `품목코드 | 품목명 | 단위` 를 적는다(**재고 숫자는 적지 않음**). 고를 품목: 냉동감자튀김, 고르곤졸라, 매드크림소스, 루토사 매쉬포테이토, 냉동마늘쫑(없으면 아무 식자재).
8. 화면 위·아래 버튼 이름을 모두 적는다(엑셀 다운로드/업로드, 저장, 마감 등).
9. 스크린샷 3장을 찍어 **KM에게만** 넘긴다(채팅·메신저). 저장소에는 올리지 않는다.
   - 1장: 왼쪽 메뉴 경로가 보이게
   - 2장: 조회 조건과 표 위쪽(열 이름 보이게)
   - 3장: 입력 칸과 버튼 부분

## 보고 표
| 칸 | 적을 것 |
|---|---|
| 1. 메뉴 경로 | 예: 경영정보 › … › 월재고마감 (찾은 후보 모두) |
| 2. 조회 조건 | 칸 이름과 고를 수 있는 값 (년월, 매장, 창고 …) |
| 3. 열 이름 | 왼쪽부터 그대로 |
| 4. 입력 방식 | 어느 열을 입력하나 · 칸 직접 입력 / 엑셀 올리기 / 둘 다 |
| 5. 단위 | 단위 값 목록, 품목 5개의 코드·이름·단위 |
| 6. 버튼 | 화면의 버튼 이름 전부 |
