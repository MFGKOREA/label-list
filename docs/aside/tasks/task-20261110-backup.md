# [Task] 매장모음 Apps Script: 15일 복구용 백업 넣기

받는 사람: 피클 → 어사이드 (구글 브라우저 작업) 또는 그록 봇
보낸 사람: 클로드 코드
상태: 대기

## 왜
지금은 매장 품목 목록 백업이 없습니다. 실수로 지우거나 [초기화]를 눌러도 15일 안이면 되살릴 수 있게 합니다.
- 매일 새벽 3시: 41개 매장 목록(매장모음 탭 + 수원·월드타워·용산 전용 프로젝트) + 이력제 기록 → 내 드라이브 "한글표시사항 백업" 폴더에 `backup-YYYY-MM-DD.json`
- [초기화] 직전 목록은 `clear-매장-날짜시각.json` 으로 따로 저장
- 15일 지난 백업은 자동으로 휴지통

## 무엇을
1. **한글표시사항 매장모음** 프로젝트 `Code.gs` 를 저장소 `apps-script/label/Code.gs` 최신 내용으로 통째로 바꾸고 저장.
2. **배포 → 배포 관리 → 연필 → 새 버전 → 배포** (대상 배포 ID `AKfycbzEZuoBNiHYs_kkxODw3WEqmLALuTG4mpvzgncyehOkNQ2v-a4qusrm-dPH2iNne77LKw` 만)
   - ⚠️ 새 배포 금지 · Drive 서비스 다시 추가 금지 · 다른 프로젝트(수원·월드타워·용산) 건드리지 않음
3. 편집기 위쪽 함수 고르는 칸에서 **`installBackupTrigger`** 를 골라 **실행** 한 번.
   - "외부 서비스에 연결" 권한을 새로 물어봅니다 → 허용 (전용 프로젝트 3곳 목록을 읽기 위해)
   - 실행 로그에 `백업 저장: backup-오늘날짜.json` 과 `매일 새벽 3시 백업 트리거를 만들었습니다` 가 나오면 성공

## 반영 확인
- `Code.gs` 안에 `복구용 백업 (매장모음 프로젝트에서만 씀)` 주석이 있으면 최신입니다.
- 클로드 코드가 `?api=1&backups=1` 로 백업 목록을 확인합니다.

## 끝나면
이 파일 `상태:` 를 `완료` 로 고치고 `docs/aside/board.md` 맨 아래에 `- 시:분 [피클 → 클로드 코드] 백업 배포·트리거 완료 (vN)` 한 줄 덧붙여 push.
