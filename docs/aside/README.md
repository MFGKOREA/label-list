# 🌉 Aside ⇄ Pickle 깃허브 브릿지 파이프라인

집 PC의 **어사이드(Aside & Claude Code)**와 폰의 **피클(Pickle)**이 깃허브 저장소를 매개체로 소통하는 자동화 파이프라인입니다.

```
┌─────────────────┐       Git Push / Pull       ┌─────────────────┐
│  집 PC (Aside)  │ ──────────────────────────▶ │   GitHub 저장소 │
│  - 웹 리서치    │                             │  MFGKOREA/      │
│  - 브라우징     │ ◀────────────────────────── │  label-list     │
└─────────────────┘                             └─────────────────┘
                                                        ▲
                                                        │ 감지 및 알림
                                                        ▼
                                                ┌─────────────────┐
                                                │   폰 (피클 / 루이)│
                                                │ - 24시간 실시간 알림│
                                                │ - 결과 요약 브리핑│
                                                └─────────────────┘
```

---

## 📂 폴더 구조

- **`docs/aside/tasks/`** (피클 ➔ 어사이드)
  - 폰에서 피클에게 *"어사이드한테 OO 조사하라고 시켜줘"* 하면 피클이 여기에 할 일(`task-*.md`)을 작성하고 푸시합니다.
  - 집 PC를 켰을 때 어사이드에게 이 폴더의 할 일을 읽게 시키면 됩니다.

- **`docs/aside/reports/`** (어사이드 ➔ 피클)
  - 어사이드가 PC에서 웹 리서치나 스크린샷 수집을 완료한 뒤 보고서(`report-*.md`)를 여기에 저장하고 푸시합니다.
  - 피클이 새 보고서를 감지하여 신우 님의 폰으로 즉시 요약 알림을 보내드립니다.

---

## 💬 어사이드(Aside)에게 시킬 때 복붙하는 프롬프트

### 1. 작업 결과를 피클(폰)로 보고하게 할 때
> "이 조사 결과(스크린샷 포함)를 `docs/aside/reports/` 폴더에 오늘 날짜 마크다운 파일(예: `report-YYYYMMDD.md`)로 저장하고 깃허브에 push해줘."
> *(영어로 시킬 때: "Save these research results to `docs/aside/reports/` as a markdown file and push to GitHub.")*

### 2. 피클이 폰에서 남겨둔 할 일을 확인하게 할 때
> "`docs/aside/tasks/` 폴더에 새로 올라온 작업이 있는지 확인하고, 가장 최근 작업을 진행해줘."
> *(영어로 시킬 때: "Check `docs/aside/tasks/` for any new tasks and execute the latest one.")*

## 🖥️ 공유 터미널: 클로드 코드 · 피클 · 어사이드

세 에이전트가 같은 저장소에서 일을 주고받습니다. 대화는 **`docs/aside/board.md`** 한 곳에 쌓습니다.

| 이름 | 어디서 | 하는 일 |
|---|---|---|
| **클로드 코드** | 클라우드 (claude.ai/code) | 앱 코드 작성·시험·배포(GitHub Pages), 작업 지시서 작성 |
| **어사이드** | 집 PC | 브라우저 작업 (구글 Apps Script 편집·배포, 웹 리서치, 스크린샷) |
| **피클** | 폰 | 새 보고 감지 → 신우 님 폰으로 알림, 폰에서 받은 지시를 작업으로 등록 |

### 주고받는 법
1. **할 일 맡기기:** `docs/aside/tasks/task-YYYYMMDD-제목.md` 를 만들고 맨 위에 `받는 사람:` `보낸 사람:` `상태: 대기` 를 적습니다.
2. **진행 알리기:** 맡은 사람이 `상태: 진행 중` → `상태: 완료` (또는 `막힘: 이유`) 로 고칩니다.
3. **결과 보고:** `docs/aside/reports/report-YYYYMMDD-제목.md` 에 결과를 적습니다. 피클이 이걸 보고 폰으로 알립니다.
4. **짧은 말:** `board.md` 맨 아래에 한 줄씩 덧붙입니다. 형식: `- 10.26 13:30 [보낸 사람 → 받는 사람] 내용`
5. 작업을 시작하기 전에 항상 `git pull`, 끝나면 `git push`. 커밋 메시지 앞에 `[클로드 코드]` `[피클]` `[어사이드]` 를 붙입니다.

### 꼭 지킬 것
- **비밀번호·토큰·개인정보는 절대 적지 않습니다.** 이 저장소는 공개이고, `docs/` 도 웹에 그대로 보입니다.
- `board.md` 는 지우거나 고치지 말고 **아래에 덧붙이기만** 합니다.
- 구글 Apps Script 는 **기존 배포를 새 버전으로 갱신**만 합니다. 새 배포를 만들면 주소가 바뀌어 39개 매장 앱이 끊깁니다.
