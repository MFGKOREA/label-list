# 발주량·프랩량 계산 앱 설정

앱 파일은 `order.html` 하나입니다. 데이터는 구글 시트에 저장되고, 시트를 연결하기 전에는 쓰는 기기(브라우저)에만 저장됩니다.

## 1. 구글 시트 만들기 (처음 한 번)

1. 구글 드라이브에서 새 스프레드시트를 만듭니다. 이름은 `발주프랩 데이터`처럼 알아보기 쉽게 지으면 됩니다.
2. 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본으로 들어 있는 코드를 모두 지우고, 이 저장소의 `apps-script/order/Code.gs` 내용을 그대로 붙여넣고 저장합니다.
4. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
   - 유형 선택: **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. **배포**를 누르고 권한을 허용하면 웹 앱 주소(`https://script.google.com/macros/s/.../exec`)가 나옵니다. 이 주소를 복사해 둡니다.

시트에는 `kv`라는 탭이 자동으로 생기고, 앱 데이터가 여기에 저장됩니다. 이 탭은 직접 고치지 마세요.

## 2. 앱에 시트 연결하기

1. 앱을 열고 **데이터 파일** 화면으로 들어갑니다.
2. 맨 아래 **구글 시트 연결**에 1번에서 복사한 주소를 붙여넣고 **저장하고 연결**을 누릅니다.
3. 연결 전에 이 기기에서 입력한 데이터가 있으면 **이 기기 데이터를 시트로 보내기**를 한 번 누릅니다.

다른 폰이나 PC에서도 같은 주소를 넣으면 같은 데이터를 함께 씁니다.

## 3. 데이터 올리기

**품목 목록** (품목이 바뀔 때만)

| 파일 | 읽는 칸 (머리글에 이 단어가 들어 있으면 자동으로 찾음) |
|---|---|
| 발주 시트 | 품목명(필수), 품목코드, 통합그룹, 업체, 발주단위, 최소, 보관위치, 즐겨찾기, 사용여부, 쉘프라이프 |
| 프랩 시트 | 프랩명(필수), 한글/별칭, 단위, Yield, 쉘프라이프 |

- **발주단위**는 `1PK/1kg`, `1BOX/25ea`처럼 적으면 됩니다. 앞이 주문 단위, 뒤가 그 안의 양입니다.
- **즐겨찾기**는 O, Y, V, 1 중 하나를 적으면 됩니다.
- **사용여부**에 `사용중단`이 들어간 품목은 목록에서 빠집니다. 같은 **통합그룹**의 다른 코드로 합쳐서 계산합니다.
- 발주 시트를 안 올리면 수불현황의 품목명으로 목록을 만듭니다.

**월별 데이터** (매달)

| 파일 | 형식 |
|---|---|
| 실제 Gross Sales | 그달 합계를 직접 적거나, Forecast 화면에 그달 실제 매출을 모두 적으면 자동 합계 |
| Line 레시피 | PDF (MG LINE RECIPE) |
| Prep 레시피 | PDF (MG PREP RECIPE) |
| 메뉴별 매출현황 | 엑셀: 중분류 / 소분류 / 수량 |
| 수불현황 | 엑셀: 품목명 + 실사출고수량(또는 출고수량, 사용량) |

레시피는 바뀐 달에만 올리면 됩니다. 안 올린 달은 지난 레시피를 그대로 씁니다.

## 4. 레시피 연결 확인

레시피의 메뉴명·재료명과 POS 메뉴명·수불 품목명은 서로 다르게 적혀 있어서, 앱이 비슷한 이름끼리 자동으로 연결합니다. **데이터 파일 → 레시피 연결 확인**에서

- 자동으로 연결된 메뉴가 맞는지 확인하고, 틀리면 고릅니다.
- 연결 안 된 재료는 품목이나 프랩을 골라 주거나 "계산에서 빼기"를 고릅니다.

한 번 고른 연결은 저장되어 다음 달에도 그대로 씁니다. 연결이 많아질수록 B(레시피) 계산이 정확해집니다.

## 5. 계산 방법 요약

- **A 수불현황**: 품목별 월 사용량 ÷ 그달 실제 Gross Sales (최근 3개월, 최근 달 비중 3:2:1). 3개월 이상 쌓이면 고정량 + 비례량(D)으로 나눠 계산합니다.
- **B 레시피**: 메뉴별 판매수량 ÷ Gross Sales × Line 레시피 (프랩 재료는 Prep 레시피 Yield로 원재료까지 풀어 계산). 2개월 이상 쌓이면 지난달 실제 ÷ 이론으로 로스를 보정합니다.
- **C 최종 발주량**: A·B 필요량(E: 최근 오차가 작은 쪽에 더 큰 비중) + 안전재고(F: 95% 기준) − 재고 − 익일 입고량 → 발주단위로 올림.
- **발주 기간**: 발주 후 2영업일 뒤 입고, 일요일은 발주·입고 없음. 오늘부터 다음 입고 전날까지 쓸 양을 계산합니다.
- **G 재고 채점**: 같은 품목의 재고를 다른 날 두 번 이상 입력하면 `지난 재고 + 익일 입고 − 이번 재고`를 실제 사용량으로 보고 채점해서 E와 F를 조정합니다. 결과는 데이터 리포트에서 주차별로 볼 수 있습니다.
