## MIS 연동 방향 (아이디어 1·2)

- 1.0 필수: 확인 화면 + 발주 목록 내보내기(텍스트·JSON). 이것만으로도 복사 입력 실수가 줄어듦.
- 자동 입력 1순위: **Aside** 시험(크로미움 AI 브라우저, 로그인된 MIS에서 대신 입력, 제출 전 승인). 확장 프로그램을 안 만들어도 됨.
- 2순위: 크롬 확장(MIS 탭 content script가 앱의 목록을 받아 폼 채움). MIS 화면 구조를 알아야 만들 수 있음.
- MIS 없이 완전 자동(아이디어 2)은 Aside 루틴(예약 실행)으로 가능하나, 회사 보안 정책(자동 로그인 허용)과 크레딧 비용 확인 필요.
