## 다시 만든다면 (11/16 KM "오늘 똑같은 목표로 처음부터 다시 시작한다면 남길 것은?")

남길 것
- 한 파일 앱 + 구글 시트 한 칸씩(KV) + 매장 PC 확장: 서버 없이 폰·PC·예약 작업이 같은 자료를 봄. 매장에 설치할 것이 확장 하나뿐.
- 계산 규칙을 "지난 날로 되돌려 보기"로만 바꾸는 방식(asof.mjs · est.mjs · regress.mjs)과 그날 뒤 자료를 자르는 규칙.
- 사용량 두 길(A 수불 · B 레시피)을 섞고 채점으로 비중을 배우는 구조, 날짜순 예상 재고, 86 계산.
- 스스로 확인(misTrust · recvTrust · 합계 대조): 읽은 자료를 믿기 전에 맞춰 보는 장치.
- 시트가 비정상이면 아무것도 안 쓰는 규칙, 쓰기 전 백업, 보안 지킴이.
- 상태 목록(STATES.md)과 계약 시험: 처음부터 있었으면 화면마다 조건을 다시 쓰지 않았을 것.

바꿀 것
- app.js 한 파일 3,800줄 → 계산(모델·사용량·86) · 동기화 · 화면으로 나눈 모듈. 계산은 화면 없이 돌릴 수 있게(지금은 시험마다 브라우저를 띄움).
- 정해진 수집·알림을 대화형 예약 작업이 아니라 스크립트가 직접 도는 곳에(사용량 한도와 무관하게).
- 시트 주소가 열쇠 없이 전체를 주는 것 → 처음부터 읽기 열쇠.
- 확장을 올리는 시험은 처음부터 가짜 서버로만(이번 사고).
- 시간 값·상태 낱말을 앱·collect.py·확장이 한 파일에서 같이 읽기(지금은 세 군데에 따로 있고 시험이 맞춰 봄).
